## Remaining application-wide work

### Sketch placement and exact CAD boundary - 2026-10-11

The installed manual PDF55-61 documents coordinate planes, offsets and placing a sketch on the slicing plane or projecting it onto the reference plane. Sketches now persist an optional rigid world frame; legacy sketches retain XY at Z=0. The editor exposes coordinate-plane placement and offset without adding a model-history operation. Exact extrusion builds the polygon at its world placement and extrudes along the frame normal. Parametric recipes retain the frame and rebuild through the same CAD request; STEP therefore contains the placed geometry. Invalid scaled, sheared, reflected or nonfinite frames are rejected before native shape registration.

The declared right-handed conventions are OXY U=X/V=Y/+Z, OYZ U=Y/V=Z/+X, and OXZ U=Z/V=X/+Y. The native screen-axis conventions remain unobserved; these conventions do not claim equivalence to recovered native implementation. This fixes a placement boundary required by scan-to-sketch creation. Scan slicing, selected-visible extraction, frozen references and saved sketch ownership are now implemented as described below. Interactive plane manipulation and full Create Sketch dialog parity remain unfinished.

### Scan-section sketch creation - 2026-10-11

The installed manual PDF55-61 documents an extruded-surface mode, coordinate planes, typed offset, slicing-plane versus reference-plane placement, selection restriction and transition to sketch editing. The dedicated Create Sketch session now captures a scan, hidden slots and selection; Apply extracts actual triangle sections in the cancellable processing worker. Hidden slots are excluded; selected-only extraction rejects an empty/stale selection rather than falling back to the entire scan. Changed options require Apply before Create. Cancel and preview do not alter the model, authoring data or model history; source geometry changes invalidate the session. Actual slice lines display in white and projected reference-plane lines in grey.

Create adds a separately owned sketch with a rigid frame and frozen local UV reference samples. Reference samples remain separate from editable points/curves and cannot be extruded as if they were a solved CAD profile. New sketches start with empty editable geometry, not the demonstration rectangle. Saved sketch entries preserve independent edits, frames and references when switched or serialized; the older standalone draft is retained. References remain available after source deletion because the source ID records provenance rather than a live dependency. Sampled imports are identified as sampled. The SVG renders large reference arrays as one path and computes bounds without argument-spread limits.

The exposed initial offset0, slicing-plane ON and selected-only OFF are application defaults, not verified native factory defaults. The section algorithm and tolerances remain independently authored. Picked primitive planes, interactive plane handles, revolved/stacked/outline extraction, contour fitting/stitching, saved-sketch visibility/context-menu parity remain incomplete. Editable lines and circular curves support model-view drawing as described below; this does not establish full native sketch parity.

### Sketch dimensions and construction references - 2026-10-11

Installed manual PDF84 documents straight, horizontal and vertical point distances; PDF86 documents construction geometry as a reference excluded from solid creation. Sketch constraints now distinguish Euclidean, horizontal and vertical distances. Directional dimensions are nonnegative coordinate separations, solved independently of the orthogonal coordinate. New relations solve before replacing the draft; conflicting or unsolved additions preserve the previous sketch. Construction lines/arcs remain in the constraint graph and are dashed in the preview, but profile extraction omits them. Existing sketches without construction flags retain their behavior; the project/sketch parsers validate the new fields and dimensions.

Deleting a point cascades only into incident lines/arcs and dependent relations; deleting a curve retains surviving point dimensions and independent constraints. This corrects the prior blanket constraint removal. Native deletion policy, sign/annotation conventions, constraint solver and interactive dimension placement remain unrecovered. The scan-section Create Sketch stage is implemented above; contextual dimension placement remains unfinished. These changes do not establish full sketch parity.

### Alignment input coverage - 2026-10-11

Manual PDF pages 49 and 54 describe fine alignment of an approximately aligned scan, using selected regions as priority data when available. Fine alignment now passes the selected visible triangle mask to the worker, or uses visible triangles when selection is empty. Sampling is bounded within that region; the derived rigid pose is applied to the entire source scan. The fixed target geometry is not changed. This uses independently authored sampled point-to-point ICP, not recovered native CAD-surface registration. Dedicated Preview/OK/Cancel dialogs, coordinate-system and interactive alignment, ordered viewport landmarks, simultaneous multi-scan fine alignment and original convergence policies remain unfinished.

Create Sketch's observed controls differ from the current polygon/constraint editor. Freeform, surfacing, CAD operations, scan preparation, registration and analysis still need separate field/default/state inventories, handler traces and original-versus-browser workflow checks. Current OpenCascade operations and authored geometry algorithms remain independent implementations. Full dialog parity and full original logic recovery are not complete.

### N-points alignment workflow - 2026-10-11

Manual PDF48-49 establishes corresponding ordered points on two objects, at least three pairs, numbered points, removal controls, Preview then OK. The dedicated N-points panel now selects an explicit fixed target and records moving/fixed viewport picks separately. Pick modes restrict raycasting to the requested object so overlapping objects can be picked independently. Numbered M/F markers follow the camera and the temporary preview pose. Remove last deletes the most recent recorded pick; Remove all clears both sets. Their exact native scope remains unverified.

Preview uses the existing independently authored paired-point worker, displays a temporary pose and leaves the model/history unchanged. Cancel restores the model pose and clears markers. OK commits one whole-scan transform, preserves triangle-slot metadata and selection state, and leaves the fixed target unchanged. New picks, removal, target changes or geometry changes invalidate a preview. To edit after Preview, choosing a pick mode first restores the original pose. Hidden objects must be shown before point picking. Factory pick sequencing, native marker manipulation, original solver weighting and exact dialog layout are not established. This closes the documented workflow gap, not complete native algorithm parity.

### Model-view line drawing and endpoint manipulation - 2026-10-12

The installed manual PDF62-64 documents dragging a line in model view, endpoint dragging, automatic constraints with a toggle, and orange free versus blue constrained endpoints. A saved sketch now exposes Navigate, Line, Move endpoint, Constraints and Normal to sketch. Plain left-drag in Line mode intersects the active rigid sketch plane and commits one line on release. With Constraints enabled, nearby existing endpoints are reused and near-horizontal/vertical lines acquire relations. The numerical solver rejects conflicting endpoint targets atomically; a temporary fixed drag relation is removed before saving. Shared endpoints and related geometry move together. Preview, Escape, pointer cancellation and editor exit release pointer capture and temporary geometry without changing authoring data. Middle-drag and Ctrl/Shift navigation remain available. Sketch authoring does not add model history; accepted CAD extrusion does.

Screen tolerances (eight pixels for snapping, ten for endpoint picking), endpoint reuse policy and the numerical solver are independently authored; the native algorithms and thresholds are not recovered. Line previews show the raw pointer endpoint until acceptance. General primitive snapping, tangent-arc creation, curve selection/contextual dimensions, reference-point painting/fitting, drag undo/redo and complete native Edit Sketch equivalence remain unfinished. Construction primitives render solid in the model view, while the SVG editor retains its dashed construction display.

### Model-view circles and three-point arcs - 2026-10-12

Installed manual PDF62-64 documents center/radius circles, three-point circles and three-point arcs. The model-view editor now appends center/radius circles on left-drag release and three-point curves after the third click. Arc picks are ordered start, point on arc, end, including major arcs. Temporary guides and picked-point markers are disposable; Escape, pointer cancellation, right-click during unfinished picks and tool changes discard them. Repeated/collinear picks, zero radii and nonfinite/unbounded coordinates reject without replacing authoring data. A successful retry clears its previous error. Existing geometry, rigid frame and frozen scan references survive appending curves and the numeric circular-profile reset.

Circles retain the existing two-arc representation. Circumcenter calculations, degeneracy thresholds, sampling and numerical constraint solving are independent implementations of the documented interaction contract; native math and general snapping remain unrecovered. Extrusion samples arcs into polygon chords at the configured tolerance, so it does not produce analytic cylindrical faces. Tangent-arc drawing, reference-point fitting, contextual dimensions, curve dragging and drawing undo remain unfinished.
