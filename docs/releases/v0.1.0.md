# ScanForge v0.1.0

The first release establishes the browser workbench's modeling foundations, scan
handling and navigation. It remains an experimental application; this release
publishes source only and does not deploy a production service.

## Modeling and scan workflows

- Scan Data Edit provides mesh/hole/boundary panels, curvature-sensitive wand,
  filled and unfilled brush strokes, straight strokes, area/through selection,
  selection growth/shrink and draggable clipping-box access. Hole fills support
  automatic, flat, tangent and curvature interpolation with semi/bridge modes.
  Component cleanup, boundary smoothing/projection, selected-area smoothing,
  defeaturing and mesh splitting are available within the documented MVP limits.
- New projects start empty with a world coordinate system. Create sketches by
  hovering and selecting an origin plane directly on the canvas; hold to choose
  among objects or planes beneath the pointer.
- Unit selection for unitless scan imports supports millimeters, centimeters,
  meters, inches and feet, with conversion into the project's millimeter frame.
- Sketch and reconstruction work includes constraint solving, parametric rebuild
  foundations and analytical geometry improvements. Unsupported ribbon commands
  remain visibly disabled; consult the capabilities document for exact limits.

## Navigation and interface

- View cube selections animate into canonical, origin-aligned views. Face views
  expose adjacent-view arrows and clockwise/counterclockwise quarter turns.
- Main contains frequently used tools. Project naming lives in the status bar,
  and the Objects header contains the count without a duplicate heading.
- Header actions use compact icons with hover labels. Unsaved projects show an
  elapsed-time reminder, and SpaceMouse settings retain a dedicated device icon.
- SpaceMouse uses the selected Classic Perspective icon, a pulsing connected
  indicator and automatic reconnect monitoring for previously authorized devices.
  Manual disconnect is respected; monitoring ends when the page closes.

## Limits

Automatic reconstruction of arbitrary scans and full native-application parity
are not established. Physical-device and large-input validation have specific
limits recorded in the validation and input-device documents. Compiled CAD
distribution remains gated by the unresolved dependency/source inventory.
