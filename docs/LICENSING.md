# ScanForge licensing policy

Recorded: 2026-10-13 (Asia/Bangkok).

The owner selected public source availability with controlled commercial rights. The repository remains intended for public inspection, contribution, and standard GitHub Actions CI/CD. Public visibility does not make its current custom license an open-source license.

## Current permissions

[LICENSE](../LICENSE) is the authoritative source license. It permits inspection, local evaluation, and local development for contributions to the official repository. Independent distributions and production services containing newly covered material require MALIEV's written permission. GitHub's applicable viewing and forking rights remain intact. Licensing is a legal boundary, not technical copy protection.

Source availability does not establish hosted-service pricing or payment entitlements. Official hosted access and production end-user distributions need separate applicable terms. No billing, export payment gate, account requirement, or application/MCP behavior is introduced by this change. Users' scans, designs, and exported files do not acquire the source license merely through processing.

## Transition from MIT

The repository previously declared MIT in its license, README, and package metadata. The preceding local repository head observed for this transition was `5b1764b42f2bc254338ca65cddd0c1c6009c8657`; this records a local observation, not proof of which versions were publicly distributed. The original MIT notice is preserved in [SCANFORGE_PREVIOUS_MIT.txt](licenses/SCANFORGE_PREVIOUS_MIT.txt).

The new terms attach to new covered material in versions distributed with them. They do not revoke earlier MIT grants, restrict previously MIT-licensed portions carried forward, or relicense third-party material. People may still create independent versions from material they received under MIT. Rewriting the current license or changing repository visibility cannot erase that limitation.

Before asserting exclusivity or publishing commercial releases, review public commits, tags, release archives, and existing contribution ownership to establish the actual licensing boundary. Do not describe all existing code as exclusively proprietary. New contributions require explicit agreement to [CONTRIBUTING.md](../CONTRIBUTING.md); earlier contributions need separate ownership and permission review.

## Public CI/CD and costs

GitHub documents free standard GitHub-hosted runner execution for public repositories. Larger runners are charged, and storage has separate allowances. Keep standard runners and monitor storage and billing settings when deploying. This licensing change does not change repository visibility, workflows, billing settings, or authorize a deployment.
