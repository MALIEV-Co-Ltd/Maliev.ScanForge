# Automatic global placement and live solver preview

Global Fine Align previously started the native refinement controller with identity poses. It refined existing placements; it did not search for an initial alignment. A search tolerance is a correspondence distance, not a promise that independently positioned scans will be registered. Native `stable` and `converged` are also distinct: the local convergence threshold is 0.001 mm, separate from the search distance.

The shared `global_alignment_preview` operation now defaults to `initialization: "automatic"`. It samples at most 6,000 triangle-corner locations per scan, anchors the scan with the largest estimated triangle surface area, scores proper principal-axis poses and refines twelve candidates with bounded ICP. The fixed sampling strategy uses 1,500 coarse samples, 3,000 fitting samples, up to 60 final iterations, and a 60% trimmed correspondence score. This is a coarse initialization strategy, not an accuracy acceptance threshold. `initialization: "current"` retains the previous refinement-only route for scans already placed with N-point or other alignment.

Coarse placement runs in one disposable worker with a 180-second lease. Full geometry uses the existing background datum-transform executor before native global refinement. A final anchored surface fit uses at most 2,000 points per scan against complete triangle surfaces, visits the strongest overlapping next scan first, and considers both the native pose and retained coarse pose. It tries 40%/80% fitting overlap and accepts improvements using the same sample IDs with distances capped at the search tolerance. Its estimated surface-index workspace is capped at 512 MiB; its disposable worker also has a 180-second lease. The final preview is staged and Apply creates one history entry. Cancellation, input invalidation, failures, expiry and disposal clear owned display poses and leave authored geometry unchanged.

During a solve, the existing bounded controller protocol publishes provisional solver matrices at query and local-solve boundaries. The viewport applies only display matrices; it does not rebuild full meshes per solver step. `global_alignment_state.progress` exposes a sequence, phase, optional preparation stage, pass, and per-scan row-major 3x4 transforms with exact Float64 little-endian bit strings. These are trial/working poses and may be reverted by the solver. They are not a claim that a scan is already correctly aligned. Preparation is labelled separately, without fabricated movement.

The initialization summary exposes its anchor and sample-fit RMS/ambiguity. Native final means, coverage, stability, convergence, application matrices, Apply/Cancel, revision checks, retry protection, leases and query/storage admission remain available through the shared MCP workflow.

Symmetric geometry and partial coverage can still produce ambiguous global candidates. Review the staged geometry and diagnostics; use N-point correspondence placement if the automatic result is ambiguous. No native-equivalence claim is made for the added coarse stage. The explicit current-pose route retains the native refinement evidence boundary.

## Automatic CAD setup

In **Scan Data → To origin / references**, choose **Automatic CAD setup**. Choose one raw mesh or point cloud as the detection reference and the objects to move together. Preview detects a supporting flat face for XY, uses the minimum-area footprint rectangle to align its long direction with X (or Y), and places the whole group at a centered base origin or minimum-X/Y base corner. Flip base chooses the opposite orientation. Register scans to each other first; CAD setup preserves their relative placement.

The same `alignment_preview` and `alignment_apply` MCP operations accept `automatic: { referenceEntityId, origin?: "center"|"corner", primaryAxis?: "X"|"Y", flipBase?: boolean, planeTolerance?: number }` instead of manual `constraints`/translation. Distances are mm. Omitted plane tolerance is max(0.01 mm, sampled bounding diagonal * 0.003). Detection uses at most 6,000 points, 384 deterministic point-plane trials plus 384 triangle-plane trials for meshes and least-squares refinement, then fits a footprint rectangle. All target points contribute to exact projected group bounds with cancellable chunks. At least 8% plane support is required; a no-plane result is an explicit failure with manual-reference recovery. Front/base intent cannot be inferred uniquely from symmetry. Outliers can affect the footprint and group bounds.

Results include `automatic` diagnostics: reference ID, effective tolerance, sample count, plane support percentage/RMS, world axes/origin, group dimensions, origin mode, primary axis and ambiguity warnings. Preview preserves original geometry and history; Apply uses the existing shared datum executor, validation, locks, cancellation, dependencies and single-history-transaction path. The GUI provides the same parameters and diagnostic values. Automatic placement is scan-derived setup, not native CAD face recognition.

## Final transform and quality receipts

For automatic mode, `outer` remains the native-pass receipt and `converged` retains that pass's strict native threshold. The later `surfaceRefinement` reports its fixed anchor, overlap-driven order, sampled fitting RMS, capped-distance before/after RMS, selected fitting fraction, sample/overlap counts, iteration stability and ambiguity. Lower fitting RMS alone cannot establish better alignment: changing the fitted overlap also changes that statistic. Candidate acceptance compares the same source sample IDs, with the same distance cap. Stopped-improving flags are not accuracy targets.

`coordinateStages` contains the authoritative per-object final matrix sequence and exact Float64 little-endian bits. Apply a separate Float32 store after each coordinate stage. Automatic mode can include coarse placement, two native setters and a final surface setter; reference scans skip their applicable identity stage. The refinement-only `current` route retains its native numerical path. The GUI shows surface-fit values and match coverage, with earlier native diagnostics collapsed for inspection; MCP exposes the same underlying information.

Reference selection estimates triangle surface area from up to 6,000 stratified facets, so scan tessellation density does not stand in for physical coverage. The same reference is kept through the automatic workflow. At each surface-fitting step, bounded overlap scoring chooses the next scan against the already aligned surfaces, allowing a bridge scan to connect a weakly overlapping scan.

Automatic surface fitting includes one bounded revisit of each moving scan against the completed group, excluding its own surface. The fixed reference stays anchored, and each revisit accepts only a non-increasing capped distance on the same fitting sample IDs. `surfaceRefinement.order` records the initial overlap-driven insertion order; returned poses and diagnostics describe the final visit.

The reference is also fitted once against the completed group, then all final poses are rebased to restore its fixed frame. This prevents the first imperfect scan pair from permanently defining group alignment. Surface diagnostics remain fitting statistics; `coordinateStages` remains authoritative for final geometry.
