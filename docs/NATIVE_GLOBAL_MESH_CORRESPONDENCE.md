# Mesh correspondence in the query worker pool

The query geometry now accepts an immutable `targetMeshes` list, distinct from its raw point/normal/label records. The list follows native group-child evaluator order. A mesh-only target has empty raw records and one or more mesh evaluators; mixed groups retain both. Source sampling still uses its original point records. No new public GUI/MCP action is advertised by this internal extension.

The target-average branch queries the prepared mesh target set with the original local query radius, mask and source label, transforms the winning projection/face normal back through the target pose, and accumulates them in the existing native order. A target can contribute when its raw point index is empty. The pooled-plane branch retains its raw-neighbourhood search and plane fit; it does not use evaluator projections. Immutable target preparation survives pose changes and repeated jobs.

The worker pool retains `targetMeshes` at its initialization boundary. When cross-origin isolation permits shared buffers, coordinates, triangle indices and byte flags use SharedArrayBuffer carriers; repeated references to a view within one geometry retain their aliases. The authored buffers remain attached and unchanged. Each physical worker prepares its own index/adjacency cache once and reuses it across jobs. The existing physical-worker limit and 512 MiB admission budget remain unchanged. Admission now includes mesh carrier bytes plus a 384-byte-per-face working estimate per worker; this is an estimate, not a measured bound on all possible octree subdivision/adjacency peaks. Large full-owner evaluator preparation remains a separate capacity and parity gate.

## Native capture

The retained-image probe extends the previously verified full correspondence harness. It executes original serial procedure `0x140ae8c70` and multicore per-cell callback `0x140ae9970`, including original transforms, accumulation, normal agreement and acceptance. Mesh cases execute the original target chooser `0x140ae87d0`, recursive query `0x1403999e0` and signed triangle leaf `0x140399e30`; raw point index construction/search remains original for mixed targets. The application fixture is `tests/fixtures/global-fine-mesh-correspondence-native.json`.

The 32 captures cover sixteen configurations in both numeric modes: open/shared edges, hidden triangles, evaluator ordering, mixed raw/mesh targets, small radius, source labels, normal rejection, multiple targets and translated/rotated poses. They contain 15 accepted pooled-plane pairs and 55 target-average pairs, including empty results. Original OS thread orchestration is not executed by the capture: the original cell callback executes directly and its outputs merge in cell order. Small manifold mesh leaf nodes, exact axis-aligned face normals and neighbour pointers are supplied. Mesh index construction and adjacency production are constrained by their separate original fixtures. Full owner-scan registration and GUI/MCP preview, Apply, cancellation and history remain unfinished.

The first probe attempt stopped on an adapter name-resolution error caused by retained CRLF text; it released its mapping and exception handler. Normalizing the generator's line endings fixed the adapter, and all 32 captures completed. The successful probe returned and released both resources. No native application files were modified. The source image SHA-256 remains `e10b727582bc2b59f2e243ee7f247642957e388fc6bb995d7931afb9e77f78d1`.

## Validation

Validation is performed against a fixed snapshot of committed baseline `9a895b2` plus the owned query/pool/test changes; unrelated dirty application work is excluded. Build precedes focused, full-suite and physical-worker browser checks. The initial compiler run found a test-adapter type error; the adapter was corrected to use the worker-input contract before the successful production build (`scanforge-529199cc0109e7b5`). Test and browser results must be recorded after execution. Resource admission is never lowered to bypass host memory pressure.

The focused suite passed 294 tests, including every native mesh correspondence case through both direct and worker-state paths, existing raw correspondence/registration regressions, shared-buffer alias retention and mesh memory admission. The full fixed-snapshot suite passed 45,312 tests across 590 suites, with zero failures and 43 optional skips. Formatting, JSON readback and owned-file name/whitespace checks passed.

The isolated Chrome replay on the current port-5173 source passed all 32 native cases twice through two physical workers (64 exact correspondence comparisons). Two additional comparisons changed both poses and returned to the original poses in the same prepared pool. Two forced single-worker comparisons retained the selected numeric mode and original outputs. Cross-origin isolation was active, so the replay exercised SharedArrayBuffer mesh carriers. All 66 owned workers initialized exactly once and terminated; no browser errors occurred. This verifies controlled kernel/pool integration, not complete owner-scan registration or a measured large-scan speedup.

The first browser replay returned matching results but shutdown was delayed; its browser and Node processes subsequently exited. Cleanup now retains the finite lease during shutdown and closes the server in a nested finally even if client close fails. The regression rerun passed the same comparisons and completed cleanup. The native probe, compiler and suite processes also exited. The validation snapshot remains retained after the earlier cleanup rejection; removal was not retried. Port 5173 remained responsive. Public command discovery and GUI/MCP contracts remain unchanged until final registration and publication semantics are verified.
