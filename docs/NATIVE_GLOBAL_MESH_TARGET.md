# Prepared mesh target adapter

`scan-native-global-mesh-target.ts` connects the verified index/facet producer and native adjacency builder to the existing target-choice function. Preparation is cached by immutable mesh/configuration identity inside each physical worker. Pose changes and repeated queries reuse the prepared index and one-byte-per-face neighbour mask. The temporary full adjacency result is not retained by the returned adapter.

The mask records pointer presence for the native triangle fields at offsets `0x28`, `0x30` and `0x38`, corresponding to bits 1, 2 and 4 in `0x140ae87d0`. It is independent of visibility filtering: a hidden neighbour still supplies a nonnull pointer. The index owns candidate filtering. This preserves the original distinction between an open boundary and a hidden adjacent face.

Each target owns reusable projection, distance, edge-flag and traversal buffers, plus a single borrowed result record. Querying passes the original caller radius to the evaluator, preserves numeric face ID zero as a valid hit, reads the selected face's Float32 normal, and attaches its neighbour mask. The result is then consumed by `nativeGlobalTargetChoice`: closest-hit arbitration precedes the boundary check, which can retain the raw fallback without retrying a farther evaluator. Callers must consume the borrowed record before querying the same target again. Query validation and hit assembly allocate no arrays, closures or per-facet records.

Cancellation is checked before cached preparation and before publishing a newly prepared target. Failed or cancelled target preparation is not cached. Existing independently successful evaluator preparation can remain cached; a target retry reuses it. Authored vertices/triangle buffers remain unchanged. Empty geometry produces a miss. Invalid adjacency references and nonfinite queries/radii are rejected.

The regression compares masks produced through the integrated adapter against all 33 retained original global-adjacency cases, in addition to the existing original facet, constructor and target-choice fixtures. Generated two-triangle cases exercise interior projection, a shared edge, an open boundary with raw fallback, hidden-neighbour presence, a subsequent miss, cache identity and cancellation. These generated integration cases are not new native full-controller captures.

The browser Worker regression also exercises the real prepared adapter on the three generated projection cases alongside the existing exact native query, extent, normal and index fixtures. Validation results are recorded after execution. This private prerequisite does not enable public Global Fine Align or modify GUI/MCP contracts. Multi-worker transport/routing, full owner-scan correspondence and final native registration comparisons, then shared preview/Apply/cancel/history integration, remain required.
