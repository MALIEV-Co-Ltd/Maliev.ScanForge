## Cylindrical Unroll

The shared implementation now narrows radial coordinates to Float32 before sqrt/acos/sign calculation. It removes facets touching angular quadrants zero and three, rechecks a removed slot after replacing it with the current last facet, and emits repeated copies with Float32 X translations. Positive offsets rotate the radial frame. The GUI and public MCP operation expose instances and create a separate owner by default; explicit replacement remains available. Resource admission, finite output, cancellation and representational-collapse checks remain enforced.

The manufactured 24-facet radius-2 mm open cylinder was imported with an exact cylindrical reference. Native exports at 0 degrees/one instance, 90 degrees/one instance and 0 degrees/two instances contain 22, 22 and 44 facets. The regression fixture `tests/fixtures/unroll-observed-cylinder.json` retains the source corners, settings, export digests and observed output corners. Arc/radial Float32 coordinates and full facet order match exactly. Axial coordinates differ by less than 1e-12 mm because the imported reference contributes a tiny frame rotation. This is a stated tolerance, not byte-identical full XYZ parity. A further 22-facet export uses a nonorigin center `[3,4,5]` and axis parallel to `[1,1,1]`; `tests/fixtures/unroll-observed-tilted-cylinder.json` and its regression also match exact arc/radial coordinates and order with the same axial tolerance. Its corrected exact reference retains an identity model placement; the initial reference with an extra placement transform was excluded.

Directional seed bytes remain absent from archived raw ranges. GUI/export evidence resolves orientation for the observed +Z fixture; it does not bind every native cylinder frame. Production still constructs a deterministic world-projected tangent, and reference binding does not retain an imported cylinder's original tangent. Arbitrary tilted/imported reference conventions, cap/axis edge cases and complete native auxiliary sketch/frame publication remain open acceptance work.

## Average Mesh

The shared implementation now chooses the first scene-order mesh with the greatest facet count, queries other indexed surfaces in scene order against original source points, rejects open-boundary hits, and accumulates/divides through Float32 stores. Authored duplicate seam identities and unused base vertex records survive; derived normals are regenerated. Aggregate input carriers are admitted before worker cloning. Default publication creates and selects a new owner; explicit replacement and the singular target alias remain available.

A native GUI run imported the same two-facet base at Z=1 mm and one-facet references at Z=0 and Z=5 mm. The dialog showed 10.000 mm by default. Its exported two-facet output has every Z=2 mm, and its entire ordered corner stream equals production output. `tests/fixtures/average-observed-planes.json` records the exact input/output and export digest. This confirms the largest-input base and new-owner behavior for that run. Focused regressions additionally cover strict tolerance edges, open-boundary rejection, ordered Float32 accumulation, indexed seams, cancellation and buffer ownership. A second native two-mesh run places every base point outside an open reference rim but inside the 10 mm search radius. Its exported two-facet corner stream is unchanged and equals production output; `tests/fixtures/average-observed-open-rim.json` retains this boundary-rejection case. More difficult native query-tie and preparation cases remain open.
