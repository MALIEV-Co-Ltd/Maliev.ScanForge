# Selection actions and viewport illustrations

Generated using the built-in image generation workflow. Transparent originals were downscaled to 256px RGBA PNGs for 26px viewport and 36px selection-action rendering. Existing accessible labels, callbacks, disabled states and GUI/MCP capabilities remain unchanged.

## Shared prompt

Silver machined geometry, warm gold selection and action accents, restrained cyan only when specified.
