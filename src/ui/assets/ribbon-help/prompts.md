# Help and Edit ribbon illustrations

All full-size ribbon commands use generated illustrations. Compact header, viewport, timeline, object-tree and status controls retain simple symbols. These images preserve existing command labels, availability and GUI/shared-operation/MCP contracts; planned commands remain planned.

Transparent originals were generated with the built-in image generation tool. Application images are 256-pixel PNGs with preserved alpha, suitable for the 40-pixel ribbon size at high pixel density.

## Common prompt

Generate exactly one high-quality realistic 3D CAD application ribbon icon. True transparent background; isolated composition filling the square canvas, no floor, outside shadows, watermark, border or unrelated decorations. No text, lettering or numbers unless explicitly requested as a glyph. Substantial readable objects with polished silver-grey machined materials, gold action accents and sparse teal references. Consistent studio lighting, clear depth and a bold silhouette readable at 40 pixels. Depict this command:
