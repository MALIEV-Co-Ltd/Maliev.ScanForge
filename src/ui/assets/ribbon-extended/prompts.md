# Extended ribbon command illustrations

Generated with the built-in image generation workflow. Transparent raster originals are retained in Codex generated images; application assets use a 256-pixel version with alpha preserved for crisp 40-pixel rendering at high pixel density.

Full-size ribbon commands use generated illustrative geometry, including Help and Edit utilities. Compact header, viewport, timeline, object-tree and status controls remain simple. Existing scan Clear and Show hidden illustrations are reused only for the same actions.

Each command remains attached to its existing GUI/shared-operation/MCP contract and availability status. Artwork does not implement or enable planned commands.

## Common prompt

Generate exactly one high-quality realistic 3D CAD application ribbon command icon. Transparent background with true alpha, isolated connected composition filling the square canvas, no frame unless explicitly specified, no floor, no external shadow, no text, lettering, logos or numbers. Studio lighting, substantial readable geometry and bold silhouette readable at 40 pixels, consistent polished grey machined materials with gold action accents and teal references; purple only when explicitly requested. Avoid tiny decorations and generic gear unless requested. Clearly communicate the actual geometry operation. Command:
