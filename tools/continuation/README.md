# Continuation reference sources

These 25 files preserve the prepared browser import diagnostics, Windows bounded
process runners, native binding helpers and ASC browser candidate. Their original
bytes and SHA-256 hashes are listed in `source-manifest.json`.

They are historical analysis sources, outside the application build. They require
fresh machine bindings and supporting evidence before execution. Absolute paths,
process IDs, source hashes and build receipts describe the original computer.
Do not treat them as current runtime authority or replace guards to make them run.
Formatting excludes this reference folder to preserve the recorded hashes.

The R6 diagnostic syntax, 16 observer contracts, four GUI import fixtures and
attribution fixture passed on the original computer. The actual R6 three-scan
browser run remains unrun. The R5 full browser attempt hit the 2 GiB process Job
limit before alignment; the sampled aggregate peak was about 1921 MiB. All 24
owned children were verified exited. These observations do not prove native
alignment equivalence or acceptable viewport performance.

The original runtime plans, reports, native module image and source datasets stay
outside Git. Transfer the analysis directory described in
[the handoff guide](../../docs/CONTINUATION.md) if continuing the exact frozen
replay. A clone alone does not contain every external dependency of these scripts.

No reference script is a production entry point. The ASC candidate must be
reviewed and integrated at the original test path before browser execution.
