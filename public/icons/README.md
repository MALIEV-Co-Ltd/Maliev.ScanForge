# Toolbar image assets

The active ribbon uses the complete independently authored vector collection in `src/ui/RibbonCommandIcon.tsx`: 122 explicit command entries across ten tabs. Golden CAD geometry, green additions and movement, coral removals, and lavender construction guides describe each operation. The SVGs render locally at 34px and remain sharp on high-density screens. Unsupported tools retain their disabled appearance and behavior. Coverage tests fail if a ribbon command lacks artwork.

The earlier transparent PNG experiments below were generated with the built-in imagegen tool on 2026-10-11 and retained as local source assets. They are superseded in the ribbon by the consistent vector set.

## edit-scan.png prompt

Create ONE professional CAD desktop toolbar icon, square canvas, true transparent background. Icon subject: EDIT SCAN. A simple golden-yellow low-poly triangulated scan of a small mechanical bracket, with an obvious graphite pencil with coral-red tip touching a triangle at its right front edge to signify editing. Orthographic three-quarter view, no perspective distortion. Clean compact flat shaded technical illustration, very few large triangular facets with thin charcoal boundaries. Strong readable silhouette designed to remain clear at 32px. Yellow object fills most canvas with 10% margin. No text, no badge, no surrounding tile, no shadow outside the object, no blue. Deliver a single isolated icon as a PNG asset.

## plane.png prompt

Create ONE isolated professional CAD toolbar icon on a truly transparent square canvas. Subject PLANE: a single flat golden yellow rectangular plane shown in an orthographic axonometric three-quarter view (no perspective convergence), appears as a precise yellow parallelogram. Simple subtle two-tone golden fill, thin charcoal edge, four small charcoal corner dots. Broad clear silhouette occupying 80% of canvas, no grid, no axes, no surrounding objects, no tile, no typography, no blue, no cast shadow outside shape. Designed to be legible at 32 pixels. Output one single transparent PNG icon.
