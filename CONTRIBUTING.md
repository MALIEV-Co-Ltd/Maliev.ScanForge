Development is coordinated in [MALIEV-Co-Ltd/Maliev.ScanForge](https://github.com/MALIEV-Co-Ltd/Maliev.ScanForge). Propose improvements through issues and pull requests to this repository. You may inspect the source, create a GitHub fork, and clone, build, test, and modify covered code locally for evaluation and proposed contributions. Earlier MIT material and third-party components retain their own permissions.

## Development and validation

Follow the setup instructions in [README.md](README.md) and preserve GUI/MCP parity under [AGENTS.md](AGENTS.md). Keep changes scoped and include applicable tests. Run the affected build, tests, and formatting checks before requesting review; state any checks not run and their blockers. Proposed licensing or third-party dependency changes require maintainer review.
